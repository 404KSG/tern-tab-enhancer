# 标签增强设计约定

日期：2026-10-16。范围：Tern 桌面端现有水平和垂直标签，首先验证本机 Tern 0.9.0。

用户要求三个变化：右侧原手动颜色圆点改为 Tty7 的 Agent 状态/数量；原手动颜色改为整行底色和 hover；移除前方图标右下角的紫色圆点。原生标题、布局、动态效果偏好和手动颜色数据保持原有含义。

## 状态与数量

采用 Tty7 当前源码的状态：工作 `#3B82F6`，等待输入 `#F59E0B`，本轮结束 `#22C55E`，未开始无点。多 Agent 优先级为等待 > 工作 > 结束 > 空闲。等待为空心小圆，工作为轻微明暗变化的实心小圆，结束为实心小圆。

只有聚合状态为结束时，显示有未查看结果的 panes 数量；一个 pane 的多个结果只算一个，查看后只清除该 pane 的未读数，不清除其他 pane。计数按 Tty7 封顶为 9（9 表示至少 9 个），为数字预留固定宽度。结束状态表示本轮交回控制权，不表示通过验收。

参考：[Tty7 状态定义](https://github.com/l0ng-ai/tty7/blob/main/crates/tty7-core/src/core/cli_agent.rs)、[聚合与未读](https://github.com/l0ng-ai/tty7/blob/main/src/ui/app.rs)、[右侧状态渲染](https://github.com/l0ng-ai/tty7/blob/main/src/ui/tab_strip.rs)。

## 布局与颜色

保留 Tern 原生标签和图标结构，不改变名称，不增加额外侧栏，不铺开原有堆叠图标。右侧固定状态槽与快捷键/关闭按钮保持间距，数量变化不改变标题宽度。隐藏图标角标仅限标签区域。

手动颜色仍由 Tern 原生颜色菜单保存，插件读取 `data-tc` / `--tc` 渲染淡底色、hover 加深、选中强调。深浅色主题分别使用 Tern 原生调色值，文字保持可读。无手动颜色的标签保留原生外观。暂停或卸载插件即可恢复原生圆点，不需要重写/恢复任何颜色数据。

彩色标签处于工作状态时，Tern 原生灰白标题渐变会覆盖手动文字颜色。展示层只把该渐变替换为手动颜色的 80%—100% 明暗，不更改原生扫光的动画时序、文字剪裁或全局动态效果设置；未设置手动颜色的标签不受影响。

Tern 0.9.0 的样式引擎不支持父级 `:has()` 选择器及 `grid-area` 简写。展示层通过完整 pane ID 命中堆叠图标的前卡，用 `grid-column` / `grid-row` 保持图标重叠，并让前卡的状态伪元素相对标签行固定定位。仅重排标签图标这一局部，不改原生标题动画或全局动态效果偏好。

## 实现边界

- `model.luau`：Agent 状态、pane 已读记录及 Tab 聚合。
- `presentation.luau`：生成局部 CSS，状态、标题身份与手动颜色分别表达。
- `host.luau`：本机完整原生 pane ID 对照，以及有界读取普通 Pi 状态桥；不保存会话正文。
- `window.luau`：极小启动入口，分别在独立回调中加载状态模块、展示模块和运行时，避免将模块编译/读取挤入 Tern 的 50ms load 钩子。
- `runtime.luau`：原生元数据与状态桥适配、事件合并、限频刷新、暂停/恢复；只有内容变化才替换样式。
- `pi/bridge.ts`：Pi 交互会话的状态桥，使用 `agent_settled` 识别最终结束，用 UI 提问开始/结束恢复原状态。只在 Tern 的交互模式启用；print、JSON、RPC 子进程不覆盖父 pane。运行标识和轮次防止重复结果/旧对话框重新制造未读，5 秒本地心跳用于约 15 秒的异常退出过期。

普通 shell 中启动的 Pi 不会出现在 Tern 的 Agent Block 列表中；它使用状态桥提供准确状态，不依赖 shell 进程整个生命周期的 busy 标记。安装器在 Pi 个人扩展目录放置该桥接文件，已有会话需在空闲时 `/reload` 或重新启动；Pi 设置、模型和指令文件不变。

比较过重建侧栏、直接改写原生 tab.color 和在现有标签上叠加显示三种方式；采用显示层方式，保留原生导航与手动颜色真值。原生状态接口缺少投影时必须测量实际调用成本；不以标题动画推测精确等待状态。

不修改 `reduce_motion`、agent_command、快捷键、Tern 源码或 Agent 的认证/模型配置。不向终端输入任务，不调用网络，不保存聊天内容。通过原生 Agent Block 上报的状态，以及 Pi 状态桥，提供精确状态；没有状态通道的普通 CLI 不伪装成精确等待/完成。

## 验证约定

执行实际 Luau 模块的行为测试，并在独立配置、独立 daemon/窗口中通过原生状态协议测试工作/等待/结束、多个 panes 计数、逐个已读、重载、颜色选择、hover、主题、水平与垂直布局。检查长时间稳定状态不会反复替换样式，也不改变标题尺寸和原生设置。
